# VICE CLOUD

Landing page inicial da VICE CLOUD, feita com Next.js.

## Rodar localmente
1. Instale Node.js (versão 18 ou superior).
2. Abra esta pasta no terminal.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra http://localhost:3000.

## Publicar na Vercel
1. Envie esta pasta para um repositório GitHub.
2. Na Vercel, escolha **Add New → Project**.
3. Importe o repositório `vice-cloud`.
4. Mantenha as configurações padrão e clique em **Deploy**.

## Importante
Esta entrega é uma primeira versão visual/interativa. Player de streaming real, autenticação, banco de dados, pagamentos PIX/cartão, histórico e painel administrativo ainda precisam ser implementados e conectados. Os planos são ilustrativos e não cobram valores. A oferta de GTA VI depende de disponibilidade, direitos/licenças e infraestrutura compatível.
